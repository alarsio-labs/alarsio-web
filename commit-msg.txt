Scaffold the repo: monorepo, docs, Claude Code tooling and CI

Sets up the foundation four people can work in parallel from, so the first
feature PR has somewhere to land.

- Turborepo + pnpm workspaces, task graph and caching in turbo.json
- CLAUDE.md as project memory: rules, four roles, module owners, conventions
- docs/ — PRD, ARCHITECTURE, FEATURES, DECISIONS, WORKFLOW, SECURITY,
  TESTING, ONBOARDING, and IMPROVEMENTS recording the nine things we are
  deliberately doing differently from the previous build
- .claude/ — four slash commands (spec, implement, review, ship), three
  subagents (module-guard, test-writer, doc-keeper) and the alarsio-module
  skill, so the architecture rules are applied rather than remembered
- CI that typechecks, lints, tests and builds through Turbo, plus two guards:
  a PR adding a migration without updating FEATURES.md fails, and any
  service-role reference anywhere in the repo fails
- The four reference PDFs and the 12-page team guide
